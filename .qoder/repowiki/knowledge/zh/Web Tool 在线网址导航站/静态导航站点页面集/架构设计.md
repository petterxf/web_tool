本模块为纯静态前端页面集合，由 Hugo（见 index.html 的 generator 注释）生成或托管，无后端逻辑。
- `index.html`：导航站主入口，左侧固定侧边栏按分类（常用工具、科研办公、悠闲娱乐、素材资源、开发设计、资讯学习）组织书签，右侧主内容区以卡片网格展示各外部网站链接；顶部集成天气插件（和风天气）、一言 API（hitokoto.cn）与多搜索引擎聚合搜索表单。
- `about/index.html`：独立子目录下的“关于我们”介绍页，使用内联 CSS 定义 about-container、skills-grid、contact-list 等样式块，并嵌入 51.la 统计 SDK。
- `commit.html`：用户提交网站的表单页，包含名称/地址/分类/描述/关键词/邮箱/联系方式字段，通过 jQuery 实现本地校验（URL、邮箱正则、必填项）与字数统计，当前未接入后端接口。
- `404.html`：极简 404 占位页。
所有页面共享同一套静态资源路径 `./assets/...`（CSS/JS/images），通过相对路径引用 Bootstrap 4.3、Font Awesome 5.15、自定义 style/custom-style 及 iconfont，依赖 jQuery 3.2.1 与 content-search.js 实现交互。
