### 网址导航
- 定义：本项目定位为“在线网址导航”工具，即一个纯前端、分类清晰的书签聚合页面，用户可按常用工具、科研办公、悠闲娱乐、素材资源、开发设计、资讯学习等类别浏览和收藏外部网站链接。
- 别名：在线网址导航、Web Tool

### 网站提交
- 定义：指用户在 commit.html 页面填写表单，将新网站信息提交到导航收录的流程。当前实现将数据暂存于浏览器 localStorage；如需持久化可对接 Vercel Serverless Functions、自建后端 API 或第三方表单服务（Formspree、Typeform 等）。
- 别名：网址提交、提交收录

### 日间/夜间模式
- 定义：页面支持切换白天与深色主题，通过 body 上的类名（如 `io-grey-mode`）及对应的 CSS 变量/样式文件实现，属于本项目的核心交互特性之一。
- 别名：深色模式、暗色主题
