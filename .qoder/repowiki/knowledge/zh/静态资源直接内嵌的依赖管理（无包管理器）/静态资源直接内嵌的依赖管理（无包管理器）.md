## 依赖管理方式

本项目是一个纯静态 HTML/CSS/JS 网站，**没有使用任何包管理器或依赖声明文件**。仓库中不存在 `package.json`、`go.mod`、`composer.json`、`requirements.txt`、`Gemfile`、`pom.xml`、`Cargo.toml`、`yarn.lock`、`package-lock.json`、`pnpm-lock.yaml`、`vendor/`、`node_modules/` 等任何依赖清单或锁定文件。所有第三方库都以**已编译/压缩后的静态文件形式直接内嵌**在 `assets/` 目录下。

## 第三方依赖清单与版本

通过扫描 `index.html` 中的 `<link>` 和 `<script>` 引用，可确认项目使用的第三方依赖及其固定版本如下：

- **CSS 框架与样式**
  - Bootstrap 4.3.1：`assets/css/bootstrap.min-4.3.1.css`

  - Fancybox 3.5.7：`assets/css/fancybox.min-3.5.7.css` + `assets/js/fancybox.min-3.5.7.js`

  - Iconfont 主题字体：`assets/css/iconfont-3.03029.1.css` + `assets/css/fonts/`（eot/ttf/woff）
  - 自定义样式：`assets/css/custom-style.css`、`assets/css/style-3.03029.1.css`

- **JavaScript 库**

## 架构约定

1. **全量内嵌策略**：所有前端依赖以“下载后直接放入仓库”的方式管理，版本号直接写入文件名（如 `bootstrap.min-4.3.1.css`），便于快速识别版本且无需构建步骤。
2. **Font Awesome 全量引入**：不仅引入 CSS，还保留了完整的 Less/SCSS/SVG/Webfont 源码目录，说明该依赖是直接从官方发行包解压而来，未做裁剪。
3. **无构建流程**：页面由 Hugo 生成（`index.html` 头部注释显示 `Hugo 0.121.0`），但 Hugo 仅用于模板渲染；本仓库提交的是最终产物，不包含 Hugo 源码或配置。
4. **无锁文件/私有源**：不存在任何 lockfile 或私有 registry 配置，更新依赖需手动重新下载对应版本的静态文件并替换。
5. **图片资源**：站点图标、Logo 等均以原始二进制文件存放在 `assets/images/` 及 `assets/images/logos/`，同样属于“内嵌式依赖”。

## 约束与风险

- **版本追踪困难**：由于缺少声明文件，依赖版本只能通过文件名推断，无法通过工具自动检测过期版本或安全漏洞。
- **更新成本高**：升级任一依赖需要人工下载新文件、重命名匹配现有命名约定、逐一替换引用路径。
- **体积冗余**：Font Awesome 完整目录包含大量未使用的 Less/SCSS/SVG 文件，增加了仓库体积。
- **CDN 依赖风险**：和风天气与一言接口为外部 HTTP 依赖，若服务不可用会影响页面功能。
- **无构建校验**：没有 lint/test/build 步骤来保证依赖一致性，不同部署环境可能因本地缓存加载到旧版 CDN 资源而产生差异。
